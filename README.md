# Suhaas Nandulamattam — Portfolio 2026 (React & Tailwind CSS)

Modern, high-performance React portfolio application converted from design specifications, featuring interactive systems architecture diagrams, live telemetry flows, playable dynamic mini-games, and responsive dark/light mode themes.

## 🚀 Quick Start

### 1. Install dependencies (if not already installed)
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```
Open your browser at the local URL (typically [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173)).

### 3. Build for production
```bash
npm run build
```
Production assets are generated in the `dist/` folder.

### 4. Preview production build
```bash
npm run preview
```

## 🛠️ Features & Highlights

- **React 18 & Vite**: Lightning-fast compilation and HMR.
- **Tailwind CSS**: Custom typography, grid background, brand palette, and dark mode support.
- **Interactive Architectural Topology**: Hoverable microservice nodes (React/TS, PostGIS, FastAPI, Groq/LLaMA, Neon/Redis) with animated telemetry flow.
- **EVrify Flagship Section**: Dynamic route planning visual along the NH48 corridor with animated path pulses.
- **Playable Dynamic Tic-Tac-Toe**: Interactive modal with customizable grid sizes (3×3, 4×4, 5×5) running an arbitrary N-dimension invariant evaluation algorithm.
- **Profile Photo Lightbox**: Click on the profile avatar to view the full high-resolution portrait.
- **Floating Pill Navbar**: Fixed navigation with scroll-spy section tracking, dark/light theme switch, and mobile menu drawer.
- **Contact Utilities**: One-click email copy with visual feedback badge and direct messaging links.
